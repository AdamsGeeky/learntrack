# 08 · Final README Project

Create a public repository named `my-developer-profile`. Its `README.md` must include:

1. Title and introduction.
2. Headings and formatted text.
3. Ordered and unordered lists.
4. A skills table.
5. At least two links.
6. An image.
7. A fenced code block.
8. A task checklist.
9. Two collapsible sections.
10. Your learning goals.

Submit the repository URL using the [submission guide](../submit.html).
