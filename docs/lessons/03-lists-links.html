GEEKINK MARKDOWN COURSE

Lists and Links

Use hyphens for unordered lists and numbers for ordered lists. Nest items with indentation. GitHub also supports task lists with [ ] and [x].

Example

- HTML\n- CSS\n- JavaScript\n\n1. Learn HTML\n2. Learn CSS\n3. Learn JavaScript\n\n[GitHub](https://github.com)
