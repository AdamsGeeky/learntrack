# 07 · Dropdowns and HTML

GitHub supports HTML `<details>` and `<summary>` for collapsible sections.

```html
<details>
  <summary>My learning goals</summary>

  - Learn Git
  - Practise Markdown
  - Build projects
</details>
```

Add `open` to `<details>` to expand it by default.

**Practice:** Add two collapsible sections to your README. Test them on GitHub.
