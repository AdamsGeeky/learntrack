GEEKINK MARKDOWN COURSE

Dropdowns and HTML

GitHub supports HTML details and summary elements for collapsible sections. The summary is the clickable title; the content appears when expanded.

Example

<details>\n  <summary>My learning goals</summary>\n\n  - Learn Git\n  - Practise Markdown\n  - Build projects\n</details>

Try it yourself

Add two collapsible sections to your README and test them on GitHub.
