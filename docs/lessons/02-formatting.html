Headings and Text Formatting

Use # symbols to create headings. Use double asterisks for bold, single asterisks for italic, tildes for strikethrough, > for blockquotes, and three hyphens for a divider.

Example

# Heading 1 · ## Heading 2 · **Bold** · *Italic* · ~~Strikethrough~~ · > Blockquote
