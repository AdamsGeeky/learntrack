Introduction to Markdown

Markdown is a lightweight markup language used to format plain text. Developers use it for README files, documentation, tutorials, changelogs and contribution guides.

Common files include README.md, CONTRIBUTING.md, CHANGELOG.md and CODE_OF_CONDUCT.md.
