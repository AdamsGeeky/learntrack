STUDENT GUIDE

Submit your work

GeekInk uses GitHub pull requests so submissions are version-controlled, reviewable and connected to each student's GitHub identity.

  1. Fork the course repository.

    Open the repository on GitHub and select Fork.

  2. Create your submission file.

    Create submissions/YOUR-GITHUB-USERNAME/markdown-profile.json in your fork.

  3. Complete the submission metadata.

    Use the JSON example below. Include the link to your own project repository.

  4. Open a pull request.

    Target the original repository's main branch. Use the assignment submission PR template.

  5. Wait for validation and instructor review.

    GitHub Actions validates the file. The instructor reviews and merges accepted work.

Submission JSON

{
  "github_username": "your-github-username",
  "assignment_id": "markdown-profile",
  "project_url": "https://github.com/your-name/my-developer-profile",
  "notes": "I completed the required README sections.",
  "submitted_at": "2026-11-01"
}
Do not submit secrets or personal sensitive information. Pull requests and files may be publicly visible depending on repository settings. Do not put passwords, API keys, phone numbers or private feedback in submission files.

Progress tracking

To record lesson progress, add progress/YOUR-GITHUB-USERNAME.json in your fork and open a separate pull request.

{
  "github_username": "your-github-username",
  "completed_lessons": [
    "01-introduction",
    "02-formatting"
  ],
  "updated_at": "2026-11-01"
}
