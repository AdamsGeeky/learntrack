INSTRUCTOR OPERATIONS

Instructor guide

Register students

Edit data/students.json. Set publish_profile to true only when the learner has agreed to public display. Learners without public profiles still contribute to aggregate counts.

Review submissions

  1. Review the pull request and linked student project.
  2. Merge only after the submission meets requirements.
  3. Keep full rubrics and private feedback in a separate private instructor repository.
  4. Publish only an approved, sanitized score record in data/published-assessments.json.
  5. Commit to main; GitHub Actions refreshes dashboard data and Pages.

Progress verification

Student lesson completion records are self-reported. Review evidence before merging if verified progress is required.

Privacy: This is a public reporting dashboard, not a private admin console. Never publish private feedback, contact information or unapproved scores. Keep confidential instructor records in a private repository.
