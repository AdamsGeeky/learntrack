## Student learning checklist

Copy this checklist into your own notes or personal student repository and tick each item as you complete it.

### Module 1 — Introduction
- [ ] I understand what Markdown is.
- [ ] I know what `.md` files are.
- [ ] I can identify common uses of Markdown.

### Module 2 — Formatting
- [ ] I can create headings and paragraphs.
- [ ] I can format bold, italic, and strikethrough text.
- [ ] I can use blockquotes and dividers.

### Module 3 — Lists and links
- [ ] I can create ordered and unordered lists.
- [ ] I can create nested lists and checklists.
- [ ] I can add hyperlinks.

### Module 4 — Tables
- [ ] I can create a table.
- [ ] I can align table columns.

### Module 5 — Code
- [ ] I can write inline code.
- [ ] I can create fenced code blocks with language identifiers.

### Module 6 — Images
- [ ] I can add an image with alternative text.

### Module 7 — Dropdowns
- [ ] I can create a collapsible section.
- [ ] I can put lists or tables inside a collapsible section.

### Module 8 — Final project
- [ ] I created my developer profile repository.
- [ ] I completed the README requirements.
- [ ] I submitted my project link for review.

> GitHub checkboxes in this shared README are not individual student records. Maintain your own copy if you want to save your personal progress.

## Final practical project

Create a GitHub repository named **`my-developer-profile`**. Add a `README.md` that contains:

1. A title and short introduction.
2. At least three heading levels.
3. Bold, italic, and blockquote formatting.
4. Ordered and unordered lists.
5. A learning checklist.
6. A skills table.
7. At least two hyperlinks.
8. At least one image.
9. A JavaScript or Python code block.
10. At least two collapsible dropdown sections.
11. Your future learning goals.

## How to submit your project

1. Fork this course repository.
2. In your fork, create `submissions/YOUR-GITHUB-USERNAME/markdown-profile.json`.
3. Use the following format and replace the sample values:

```json
{
  "github_username": "your-github-username",
  "assignment_id": "markdown-profile",
  "project_url": "https://github.com/your-github-username/my-developer-profile",
  "notes": "I completed the required README sections.",
  "submitted_at": "YYYY-MM-DD"
}
```

4. Open a pull request to the original GeekInk course repository's `main` branch.
5. Wait for the automated validation and instructor review.

[Read the full submission guide](docs/submit.html).
